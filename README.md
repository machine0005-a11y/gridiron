# Gridiron

An arcade football game you can play in your browser. Import your fantasy
league, play your real weekly matchup, and send the result to your group chat.

Play: https://machine0005-a11y.github.io/gridiron/

- No install, no account. Works on phones.
- Import a Sleeper or public ESPN league by URL, or type a roster by hand.
- Original game. Not affiliated with any league, players' association,
  or any existing football title. Player names are text labels supplied by you.
